# Conecta Bienestar — portal demostrativo

Página web estática (HTML, CSS y JavaScript). No necesita instalación.

## Archivos

| Archivo | Para qué sirve |
|---|---|
| `index.html` | Estructura de la página |
| `styles.css` | Diseño (colores, tipografía, animaciones) |
| `data.js` | **Contenido**: beneficios, novedades y preguntas frecuentes |
| `app.js` | Interacción (fichas, filtros, menú, formulario) |
| `assets/presentacion.mp4` | Video de presentación (40 s) |
| `assets/poster.jpg` | Imagen de portada del video |

## Completar la información de un beneficio

Abre `data.js`. Cada campo con el valor `PENDIENTE` aparece en la página como
"Por completar con información oficial". Reemplázalo por el texto entre comillas:

```js
requisitos: "Tener contrato vigente con Falabella Retail.",
```

## Publicar en GitHub Pages (gratis)

1. Crea un repositorio público en GitHub, por ejemplo `conecta-bienestar`.
2. Sube **el contenido** de esta carpeta (que `index.html` quede en la raíz).
3. En el repositorio: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
4. En 1–2 minutos la página queda en `https://TU-USUARIO.github.io/conecta-bienestar/`.

## Código QR para el afiche

1. Copia la dirección publicada (paso 4).
2. Genera el QR con esa dirección y descárgalo en PNG o SVG de alta resolución.
3. Insértalo en el afiche con un tamaño mínimo de 3 × 3 cm y margen blanco alrededor.
4. Pruébalo con varios teléfonos (Android e iPhone), con datos móviles y wifi.

> El QR debe apuntar a la página publicada, nunca a un archivo del computador.
